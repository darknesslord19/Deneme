# Darknes Player

Profesyonel Android müzik + video oynatıcı (Kotlin, Jetpack Compose, Media3/ExoPlayer).

## Özellikler
- **Müzik:** şarkı / albüm / sanatçı / favori sekmeleri, arama, karıştır, tekrar, çalma sırası, arka planda çalma + bildirim/kilit ekranı kontrolleri, uyku zamanlayıcı (yumuşak kısma)
- **Visualizer:** 10 stil — Neon Çubuklar, Ayna, Dairesel, Dalga, Parçacık, Halkalar, Sıvı Küre, Dağlar, Galaksi, LED Matris (gerçek zamanlı FFT)
- **Şarkı sözü:** senkron (LRC) karaoke dolum efekti, otomatik kaydırma, satıra dokunup atlama, zaman kaydırma (±0,25 sn), LRCLIB'den otomatik/manuel arama, .lrc içe aktarma
- **Ses efektleri:** çok bantlı ekolayzır + 12 hazır ayar, bas güçlendirici, 3D surround, ses yükseltici, yankı, hız/perde (Nightcore, Slowed…)
- **Dinamik tema:** albüm kapağından renk çıkarma, bulanık arka plan, dönen plak kapağı + basa göre nabız
- **Video:** çift dokunuşla ±10 sn, kaydırarak parlaklık/ses/ileri-geri, ekran kilidi, PiP, görüntü oranı modları, hız, ses parçası ve altyazı seçimi, harici altyazı (.srt/.vtt/.ass), video filtreleri, ses yükseltme, kaldığın yerden devam, klasör filtreleri
- Dosya yöneticisinden ses/video açma
