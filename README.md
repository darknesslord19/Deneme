# Klip Stüdyo

CapCut tarzı, telefonda çalışan video editörü (Android APK).

- Fotoğraf + video ekleme, sıralama, kırpma, süre ayarı
- 14 filtre, 13 efekt (glitch, VHS, kar, kalpler, konfeti, ışık sızıntısı…)
- Ken Burns hareketleri (yakınlaş, kaydır, ritim nabız…)
- 14 geçiş (solma, it, zoom, daire, dönme, glitch…)
- Animasyonlu yazılar (daktilo, neon, dalga, patla…) ve yazı klipleri
- Uygulama içinde üretilen 5 telifsiz müzik veya kendi müzik dosyan
- 6 hazır şablon, 9:16 / 16:9 / 1:1 / 4:5, 720p / 1080p MP4 dışa aktarma

APK, GitHub Actions ile derlenip **Releases** bölümüne konur.
